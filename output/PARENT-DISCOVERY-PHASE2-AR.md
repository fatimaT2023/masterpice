# رفيق — المرحلة الثانية: اكتشاف احتياجات الطفل وملخص الدعم

١١ نوفمبر ٢٠٢٦. المرحلة الثانية فقط. لم تتغير صفحات المختص أو الإدارة أو ملفات `shared/`، وبقي عمل Codex والمرحلة الأولى كما هما. لا يوجد commit.

## الرحلة

إنهاء حكاية الطفل (المرحلة الأولى) ← **حالة التشخيص** ← *(للتشخيص فقط)* أي تشخيص + هل في مختص بتابع ← **المجالات** ← **المواضيع** ← **شو أكثر إشي بساعد** ← **ملخص الدعم** ← الرئيسية.

- صفحة جديدة واحدة: `support-discovery.html`، داخل الخطوة ٣ من شريط الإعداد بنفس هوية المرحلة الأولى (زجاج، وردي للبنت، أزرق للولد).
- الخطوات اللي ما بتنطبق بتنشال تلقائيًا، ونقاط التقدّم بتتغيّر حسبها.
- كل شاشة فيها: عنوان، سطر قصير، زر رئيسي واحد، «رجوع»، و«تخطّي» وين ما كان مناسب.
- من أول سؤال، «رجوع» بترجّع لحكاية الطفل. «تخطّي هلأ» بينهي الإعداد وبيفتح الرئيسية بدون ما يحفظ أي إجابة.

## منطق حالة التشخيص

| اختيار الأهل | الخطوة التالية | يُحفظ في `supportProfile` الحالي |
|---|---|---|
| عنده تشخيص من مختص | اختيار التشخيص من المواضيع + ملاحظة اختيارية (٣٠٠ حرف) + هل في مختص بتابع | توحد ← `diagnosed_following` أو `diagnosed_no_followup` مع `autism`؛ مواضيع النطق ← `speech_language`؛ غيره ← `other` |
| عم نعمل تقييم | المجالات ← المواضيع | `worried` |
| عندي مخاوف بدون تشخيص | المجالات ← المواضيع | `worried` |
| بدي أتابع النمو فقط | المجالات اختيارية، «النمو بشكل عام» مختار مسبقًا | `none` |
| بفضّل ما أجاوب | المجالات اختيارية | `skipped` |

- لا تشخيص ولا استنتاج من العمر أو الأعراض أو إجابات الحكاية. التشخيص مش شرط لأي خدمة.
- إجابات الحكاية بس بتحط إطار منقّط «ذكرتوه» على المجال. ما بتختار عن الأهل.
- المشاعر والاختلافات الحسّية والمتلازمات ما بتنقترح أبدًا من الحكاية. بتظهر بس إذا اختارها الأهل.
- إذا غيّر الأهل الحالة من «تشخيص» لغيرها، المواضيع اللي اختاروها بتضل كمخاوف وما بتضيع.
- التعديل لاحقًا من بطاقة الدعم في ملف الطفل أو الرئيسية: بتفتح الملخص أولًا، وبعدها «تعديل الإجابات».

## التوحد

لما ينختار التوحد، بتظهر ست بطاقات، وكل بطاقة مربوطة بخدمة موجودة فعلًا:

- التواصل والنطق ← دليل مختصي النطق + بطاقة «تعرّفوا على طفلي»
- الروتين البصري ← لوحات «أولًا، بعدين»
- التفضيلات الحسّية ← بطاقة الطفل
- الأنشطة واللعب ← نشاط اليوم
- المشاعر والسلوك ← «اوصفوا اللي مقلقكم»
- إيجاد مختص ← الدليل

مع النص: «كل طفل متوحّد مختلف».

أدوات التوحد الخاصة (بطاقة الطفل، الروتين البصري، التفضيلات الحسّية) بتتبع قاعدة Codex الموجودة: بتنفتح بس مع تشخيص توحد مسجّل. مع «مخاوف» عن التوحد بتظهر في الملخص بعبارة «بتنفتح مع تشخيص توحد مسجّل»، بدون رابط، وما بتنعرض كأولوية. مع التشخيص بيظهر كمان «مسار دعم التوحد» الموجود.

## تغطية المجالات الـ١١ والمواضيع الـ٣٢

الخدمات مأخوذة حرفيًا من `support-catalog-data.js`. كل موضوع بيضيف كمان دليل المختصين مفلترًا على تخصّصه (نطق، نفسي، نمو، أطفال).

| المجال | المواضيع ← الخدمات الموجودة |
|---|---|
| النمو والتطوّر | التوحد ← بطاقة الطفل، روتين بصري، تفضيلات حسّية، نلعب سوا · تأخر النمو ← ملاحظات النمو، نلعب سوا · الحركة والتناسق ← النمو، السجل الصحي · النمو بعد الولادة المبكرة ← النمو، السجل الصحي |
| النطق واللغة | تأخر النطق ← النطق، نلعب سوا · أصوات الكلام ← النطق · التأتأة ← النطق · التواصل الاجتماعي ← النطق، النمو |
| السلوك والانتباه | فرط الحركة ← اوصفوا القلق، نلعب سوا · نوبات الغضب والانتقالات ← اوصفوا القلق، النمو · الاندفاع ← اوصفوا القلق |
| المشاعر والصحة النفسية | قلق الانفصال ← اوصفوا القلق · القلق والصعوبات العاطفية ← اوصفوا القلق، السجل الصحي |
| التعلّم | التعلّم المبكر ← النمو، نلعب سوا · صعوبات تعلّم مسجّلة ← النمو، لاقوا مختص |
| الاختلافات الحسّية | الصوت والضوء ← السجل الصحي، اوصفوا القلق · اللمس والملمس ← السجل الصحي · البحث عن الإحساس ← النمو، السجل الصحي |
| التغذية | الانتقائية ← ملاحظات التغذية · المضغ والبلع ← السجل الصحي، لاقوا مختص · حساسية الطعام ← السجل الصحي |
| النوم | روتين النوم ← ملاحظات النوم · الاستيقاظ الليلي ← ملاحظات النوم، السجل الصحي |
| الصحة الجسدية | السمع ← السجل الصحي، النطق · النظر ← السجل الصحي · حالة مستمرة ← السجل الصحي، المواعيد |
| المتلازمات الوراثية | داون ← النمو، السجل الصحي، النطق · متلازمات أخرى ← السجل الصحي، النمو، لاقوا مختص |
| التفاعل والحياة اليومية | الصداقات ← نلعب سوا، اوصفوا القلق · الحضانة ← اوصفوا القلق، نلعب سوا · الاستقلالية ← النمو، نلعب سوا · الحمّام ← السجل الصحي، النمو |

- إذا اختار الأهل مجالًا بدون مواضيع، بتظهر خدمة المجال الأساسية.
- «النمو بشكل عام» بيعرض ثلاث خدمات: النمو، اللعب، السجل الصحي.
- ما في أدوات جديدة. النوم والتغذية ضلّوا على الملاحظات الصحية لأنه ما في يوميات متخصصة.

## ملخص الدعم

- بطاقة الطفل بلونه.
- حالة التشخيص «حسب ما شاركتوا».
- المجالات، والمواضيع (التشخيص بشارة واضحة)، والأولويات بنجمة.
- «مصادر ممكن تفيد»: الأولويات أولًا، مع «لـ: اسم الموضوع» لكل خدمة.
- ثلاث خطوات مقترحة: ابدؤوا بأولوية، جرّبوا أول نشاط (صفحة الترحيب المعتمدة)، الرئيسية.
- العبارة: «حسب المعلومات اللي شاركتوها، هالمصادر ممكن تفيدكم». وفي الأسفل: «هذا مش تقييم ولا تشخيص».

## البيانات

- حقل جديد واحد: `child.supportDiscovery` (version 1)، فيه: الحالة، التشخيصات، الملاحظة، المتابعة، المجالات، المواضيع، المتابعة العامة، الأولويات (حد ٣)، مجالات التوحد، revision.
- الحفظ بكتابة وحدة للطفل المعني فقط، مع رفض التعديل القديم من تبويب ثاني.
- `supportData` وباقي السجلات ما بتتغير. العائلات القديمة اللي اختارت دعم قبل هيك بتنفتح بنفس معناها.

## ملاحظات للمرحلة الثالثة

- الرئيسية ما تغيّرت بعد. اقتراحاتها ما زالت تعتمد على أهداف الحكاية، مش على `supportDiscovery`. ربطها مكانه المرحلة الثالثة.
- إذا ترك الأهل الاكتشاف بالنص وفتحوا الرئيسية، بتوديهم لصفحة الترحيب الحالية (قاعدة موجودة من قبل).
